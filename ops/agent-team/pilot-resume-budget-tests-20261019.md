# Pilot: autonomous safety tests for resumable review-budget quotations

Objective: Demonstrate one complete **real Codex Builder + independent Generality and Quality audit** on a small already-approved internal tooling change, without product writes. The task is deliberately limited to deterministic test additions; existing supervisor logic must not change.

Acceptance (ALL REQUIRED):
1. Add exactly two or three NEW meaningful pytest cases in `tests/runtime/test_agent_cycle_supervisor.py` about the already-existing pure `remaining_resume_review_quote(state, quote)` function. Cover (a) a review checkpoint that has **no completed reviewers** and therefore keeps the entire required review reservation; (b) a checkpoint with completed prefix reviewers where the quote correctly deducts their reservations, preserves remaining order, and does not mutate the input quote/state; and (c), if this is not already fully covered by existing tests, a malformed/out-of-order completed reviewer set that raises `CycleError` instead of misquoting. These are ordinary behavioral assertions against real code, no fake green stubs.
2. Edit ONLY `tests/runtime/test_agent_cycle_supervisor.py`. Do not edit `scripts/odyssey_agent_cycle.py`, other test files, policy, AGENTS.md, documentation, runtime, UI, n8n or any other files. Do not commit from the model. Do not duplicate tests with exactly equivalent inputs already in the suite; choose distinguishable boundary cases.
3. Keep all assertions source-independent (no special feature names), small, fast and provider-free. Run focused pytest and Ruff if feasible in the restricted Codex shell; if that shell cannot import dependencies, report that fact and let the authoritative supervisor host gate decide. NEVER remove tests, downgrade requirements, fake outputs or loosen safety policy.
4. The human-facing outcome is NOT Odyssey product release readiness. Supervisor must run its authoritative complete Python+JS/ledger/Ruff gate after Builder; two independent read-only specialist reviews must PASS. If any reviewer finds a real repairable defect, the job may repair only within the original bounds and budget. No deployment, merge, push, real data, credential access or network changes.

This is normal-risk INTERNAL TOOLING (`--acceptance tooling --risk normal`): required independent reviews Generality and Quality. QA/Performance model reviews are explicitly omitted by current policy, but all deterministic test gates remain required.
