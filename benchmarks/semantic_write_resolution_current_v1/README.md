# Current-schema bounded-source semantic WRITE successor v1

This provider-free definition succeeds the historical `semantic_write_resolution_v1` relational
sentinels without rewriting them. Historical SWR07/SWR08/SWR10 intentionally retain their
event-like source represented as `journal_entry`; those consumed registries, evaluator, runner, and
evidence remain immutable historical artifacts.

The current successor uses the canonical `document` source `Directorio Faro`. Its one grounded fact
links the bounded Clara/Marta/Ana member set, while member notes carry the qualifiers used by the
three cases. The cases cover one qualified bounded-source target, one bounded fact reference, and
two separately qualified bounded fact references while `sábado` remains literal.

The evaluator is deliberately generic: it requires a bounded existing source, singular member
semantics, preserved qualifiers, and correct reference/literal separation. It does not require a
`document` implementation branch or add Event, Journal, or Calendar planner rules. No live model
call, accepted-contract change, or live-validation claim belongs to this provider-free slice.
