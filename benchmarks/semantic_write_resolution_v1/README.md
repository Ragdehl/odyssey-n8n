# Semantic WRITE resolution v1

This is the focused live gate for the WRITE planner contract introduced after the relational READ stabilization work. It validates only the changed model-facing distinction: Luna describes the mutation target and fact references as semantic identity queries; Core owns retrieval, canonical identity resolution, and link binding.

The historical five frozen Spanish cases cover a real self relationship, a possessive-but-not-self target, a contextually described target, a described target plus a described fact reference, and a genuinely unsupported pronoun that must fail closed. The current active-schema registry has ten Luna/low cases: those sentinels plus the rich-daughter regression, a generic existing-source relation, the exact event-participant target that exposed source/qualifier leakage, the combined relational-target + described-reference request, a counter-sentinel proving that one independently true predicate over two subjects remains two material writes, and the real DEV regression where one relational target contains two separately described fact references that must each stay bounded to the same event-member set while a day literal remains plain text. The runner is planner-only and never executes a returned action against a vault.

The runner calls `OpenAILunaExperimentalPlanner` directly. Maximum provider calls equal the number of cases, automatic retries are zero, and there is no Sol fallback path. Evidence is written incrementally to a fixed non-overwriting JSONL path and execution stops on the first failing case.

`MAX_COST_USD` is reset to `$0.00`. The historical `cases.json` remains frozen for prior evidence; current-contract evidence reads `cases_active_schema.json`. The runner requires `--confirm-live-provider-calls`, uses zero automatic retries and zero Sol fallback calls, writes incrementally, and stops on the first failing case. Evidence paths are immutable and non-overwriting. The consolidated v4 gate below consumed `semantic-write-resolution-v1-active-schema-v4.jsonl`; the first relational fact-reference attempt consumed v5 and failed closed, and the tightened provider contract consumed v6 before stopping on a semantic oracle failure. The authorized v7 artifact is retained, and the non-overwriting v8 path is reserved at `$0.00` for the strengthened generic participant-reference rule.
